Bienvenido a nuestra tienda

Encuentra componentes electrónicos para tus proyectos, prácticas y trabajos de laboratorio.

Tenemos microcontroladores, sensores, protoboards, resistencias y otros accesorios.

Calidad y variedad para tus proyectos electrónicos.

La placa Arduino UNO es una opción popular para comenzar a desarrollar proyectos. También puedes utilizar la función digitalWrite() para controlar dispositivos.

Los componentes se identifican mediante diferentes especificaciones técnicas. LED significa diodo emisor de luz.
